# Projet Écosphères

Le projet Écosphères gère le portail des données de la transition écologique et de la cohésion des territoires, disponible sur [ecologie.data.gouv.fr](https://ecologie.data.gouv.fr/).

Ce dépôt sert de guichet technique au projet.
